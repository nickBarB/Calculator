# Calculator

Учебный консольный калькулятор 

Запуск из корня:

```sh
java src/Calculator.java
```

Вводи первое число, операцию (`+`, `-`, `*`, `/`) и второе число
по приглашениям, каждый ответ — на отдельной строке:

```text
2
+
2
```

Результат используется в следующей операции. При ошибке повтори текущий ответ.

При текущем результате `0` можно ввести новое число или операцию от нуля.

- `c` — обнулить результат.
- `s` — выйти.
